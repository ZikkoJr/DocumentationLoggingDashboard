## Final behavior summary

- Blank and Broken percentages are separate.
- A zero Blank or Broken numerator creates no threshold finding.
- A positive exact percentage through 50%, inclusive, creates a Warning.
- An exact percentage above 50% creates a Failure.
- Blank cells do not fail populated-value validity checks.
- Broken denominators represent applicable nonblank values.
- Automatic Blank denominators follow Total Data Rows.
- Automatic Broken denominators equal the matching Blank denominator minus
  Blank Count, including a manual Blank denominator.
- Manual Blank and Broken overrides persist independently; Auto restores the
  current calculation.
- Warning-only reports save as Pass with Warnings. Active-Failure reports save
  as Fail. A handled Failure retains Failure severity and, when no Active Failure
  remains, the approved status is Pass with Warnings.
- Free-text drafts commit on `Validated` and explicit workflow/action
  boundaries. Readiness and save flush all pending text first.
- Hotel/PMS PDF copies use the same generated byte payload and are byte-identical.
- QAReportIndex records one logical entry with the final status.
- Overwrite detection uses Hotel ID and File Month as the logical key; a changed
  QA Date replaces the old logical pair only after confirmation.

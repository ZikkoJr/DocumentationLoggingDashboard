The current P1 correction remains uncommitted and no fresh technical result is claimed merely by this documentation edit.

The controlled status vocabulary in this matrix is exactly `Pass`, `Fail`, `Blocked`, `Not Run`, and `Not Applicable`. The controlled execution-type vocabulary is exactly `Direct GUI test`, `Service or harness test`, `Source inspection`, and `Manual test pending`.

No historical Phase 10 result is classified as `Direct GUI test`: no human-visible WinForms session was controlled during that run. A `Source inspection` Pass means only that the implementation path was inspected and matched the stated contract; execution was not performed for that row. A `Manual test pending` row is always `Not Run`. The four `Fail` rows `P10-DEF-001` through `P10-DEF-004` are retained historical reproductions of defects that were corrected; their paired `-T` rows preserve the historical retest results.
